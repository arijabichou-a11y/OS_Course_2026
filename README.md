## Description
This repository contains a simple Bash script developed for the Operating Systems course. 
The script retrieves and displays essential system information:
1.  **OS & Kernel Version:** Using the `uname -a` command.
2.  **Current User:** Using the `whoami` command.
3.  **Current Directory:** Using the `pwd` command.

## How to Run the Script
To test this script in a Linux environment (like Killercoda or Ubuntu terminal):

1. **Give execution permissions:**
   ```bash
   chmod +x system_info.sh
